Bulk Import Exercises

Paste a JSON array of exercises. Each exercise needs: title, muscle, sub, desc. Optional: diff, premium, videoURL.

Example: 
[
  {
    "title": "Incline Dumbbell Press",
    "muscle": "chest",
    "sub": "Upper Chest",
    "desc": "Set bench to 30-45 degrees. Lower dumbbells to chest...",
    "diff": "Intermediate",
    "premium": false
  }
]

Paste CSV rows. First row must be headers. Required columns: title, muscle, sub, desc. Optional: diff, premium, videoURL.

Example: 
title,muscle,sub,desc,diff,premium
Bench Press,chest,Middle Chest,Lower bar to mid-chest...,Beginner,false
Squat,legs,Quads,Feet shoulder-width...,Intermediate,false

One exercise per line. Format: Title | muscle | sub-category | description. Difficulty defaults to Intermediate.

Example: 
Bench Press | chest | Middle Chest | Lower bar to mid-chest, drive through chest
Squat | legs | Quads | Feet shoulder-width, hip crease below parallel
Face Pull | shoulders | Rear Deltoid | Cable at head height, pull to face
Valid muscle groups: chest back legs shoulders arms core fullbody physio

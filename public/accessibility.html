הצהרת נגישות

RepCast מחויבת לנגישות דיגיטלית לכלל המשתמשים, לרבות אנשים עם מוגבלויות

תואם לתקן ישראלי 5568 ו-WCAG 2.1 ברמה AA

מצב הנגישות

אתר זה עומד בדרישות תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), תשע"ג-2013, ועומד ברמת AA של תקן WCAG 2.1 ותקן ישראלי TI 5568.
רמת תאימות: WCAG 2.1 AA
הבדיקה האחרונה בוצעה במאי 2025 על ידי צוות הפיתוח של RepCast

התאמות נגישות שבוצעו

ניווט ומקלדת

  • כל פונקציות האתר ניתנות לתפעול מלא באמצעות מקלדת בלבד
  • סדר Tab הגיוני ועקבי בכל דפי האתר
  • קישור "דלג לתוכן" מופיע בלחיצת Tab ראשונה בכל דף
  • מיקוד מקלדת גלוי ובולט בכל האלמנטים האינטראקטיביים

קוראי מסך ותמיכת ARIA

  • תגיות ARIA מלאות על כל אלמנטים אינטראקטיביים (role, aria-label, aria-expanded)
  • כותרות היררכיות תקינות (H1 → H2 → H3) בכל הדפים
  • תיאורי alt על כל התמונות והאיקונים
  • אזורי ניווט מסומנים: header, main, nav, footer
  • הודעות סטטוס מוכרזות ל-screen reader באמצעות aria-live

ויזואלי וצבעוניות

  • ניגודיות צבעים עומדת בדרישות WCAG AA (יחס מינימלי 4.5:1)
  • גופנים קריאים בגדלים מינימליים של 14px
  • מידע לא מועבר באמצעות צבע בלבד
  • תמיכה בהגדלת טקסט של עד 200% ללא איבוד תוכן

תפריט נגישות מובנה

  • כפתור נגישות קבוע ונגיש בכל דפי האתר
  • שינוי גודל טקסט (הגדלה והקטנה)
  • מצב ניגודיות גבוהה
  • מצב בהיר / כהה
  • מצב גוני אפור
  • גופן קריאות מוגברת
  • הדגשת קישורים
  • עצירת אנימציות
  • שמירת העדפות בין ביקורים
  • קריאה בקול (Text-to-Speech) — האתר מציע פונקציית קריאה בקול המשתמשת ב-Web Speech API המובנית בדפדפן. לחוויה מיטבית ולתמיכה מלאה בעברית מומלץ להשתמש בנקרני מסך ייעודיים כגון NVDA (Windows), VoiceOver (Mac/iOS) או TalkBack (Android)

מגבלות ידועות

למרות מאמצינו, ייתכנו מספר תחומים שטרם הושלמה הנגישות שלהם במלואה:

  • חלק מתוכן הווידאו המועלה על ידי מאמנים עשוי לא לכלול כתוביות — מאמנים מוזמנים להוסיף תיאורים מפורטים
  • פונקציית הקריאה בקול המובנית תלויה בתמיכת הדפדפן ב-Web Speech API ובשפה העברית — לתמיכה מלאה מומלץ להשתמש בנקרן מסך ייעודי
  • ממשק ניהול הספריה עשוי לא להיות מותאם במלואו לכל עזרי הטכנולוגיה המסייעת

אנו עובדים לשיפור מתמיד ומצפים לטפל במגבלות אלו בגרסאות הבאות.

טכנולוגיות נגישות

האתר נבנה תוך שימוש בטכנולוגיות הבאות לתמיכה בנגישות:

  • HTML5 סמנטי עם תגיות ARIA מלאות
  • CSS עם תמיכה ב-prefers-reduced-motion ו-prefers-color-scheme
  • JavaScript לניהול מיקוד ולהודעות נגישות דינמיות
  • תמיכה מלאה בדפדפנים Chrome, Firefox, Safari, Edge
  • בדיקות תאימות עם NVDA, VoiceOver ו-JAWS
